# 数字列回到原位

`bd14a84` 删掉横线时，把 `heroBlock` 里那块 874×402 的定位视图也删了。`SvgText` 的 alignment guide 只对同一个 `ZStack` 里的兄弟生效，不会传到外层。没有这块全板视图时，每一列的外框左上角变成对齐原点，左右两组就被外层 `.frame(..., alignment: .topLeading)` 叠到左上角。横线仍然不画。定位改回一块不绘制、不接点击的 `Color.clear`，尺寸与原来的横线画布相同，仍放在数字那个 `ZStack` 里面。中间上移、车道开口、分页手势没动。

界面测试增加 `CleanHeroUITests.testSpeedAndPowerStayOnOppositeSides`，检查 36 在左半、12 在右半，标签和单位跟各自的数字同一列，左右不重叠。原来的两项只点分页，发现不了这个问题。这台机器没有 Xcode，没有跑这项测试。
